# CSS 블록 관리 (PocketRisu 플러그인)

PocketRisu의 Custom CSS를 제목이 붙은 블록 여러 개로 나눠 관리하는 플러그인입니다. 켜진 블록을 위에서부터 합쳐 Custom CSS 칸 하나에 저장하므로, 앱은 지금처럼 하나의 CSS로 인식합니다.

## 설치

1. [`PocketRisu-CSS-Blocks.js`](PocketRisu-CSS-Blocks.js)를 내려받습니다.
2. PocketRisu **설정 > 플러그인**에서 파일을 추가합니다.
3. 설정 메뉴에 **CSS 블록 관리**가 생깁니다.

처음 열 때 동의 창이 두 번 뜹니다. 둘 다 허용하세요.
- **데이터 접근:** Custom CSS를 읽고 저장하는 데 필요합니다.
- **화면 접근:** 새로고침 없이 바로 반영하는 데 씁니다. 거절하면 저장은 되지만 새로고침해야 반영됩니다.

거절은 앱이 영구적으로 기억합니다. 실수로 거절했다면 **설정 > 플러그인**에서 이 플러그인의 "권한 응답 초기화"를 누르세요.

## 사용법

- **[+ 블록]:** 빈 블록을 추가합니다. 제목을 정하고 CSS를 붙여 넣으세요.
- **블록 막대:** 체크박스로 켜기/끄기, `[↑][↓]`로 순서 변경, `[접기]`, `[삭제]`(두 번 눌러 확인)
- **[적용]:** 켜진 블록을 합쳐 Custom CSS에 저장하고 화면에 바로 반영합니다.
  - `@import` 줄은 자동으로 맨 앞으로 모읍니다. 다른 규칙 뒤에 있는 `@import`는 브라우저가 무시하기 때문입니다.
  - 각 블록 앞에 `/*[[pkr-block: 제목]]*/` 주석을, 맨 앞으로 모은 `@import` 줄 끝에는 `/*[[pkr-import: 제목]]*/` 주석을 붙입니다. 가져올 때 이 주석으로 블록을 다시 나눕니다.
- **[합친 결과 보기]:** 실제로 저장될 CSS를 미리 봅니다.
- **[이전 CSS 되돌리기]:** 마지막 [적용] 직전의 Custom CSS로 되돌립니다. 블록 목록은 그대로입니다.
- **[현재 CSS 가져오기]:** 지금 Custom CSS를 새 블록으로 추가합니다. 처음 열 때는 자동으로 한 번 실행됩니다.
  - `/*[[pkr-block: 제목]]*/` 주석이 있으면 그 주석대로 여러 블록으로 나누고, `@import`도 원래 블록으로 돌려놓습니다. 다른 기기에서 쓰던 CSS나 남에게 받은 합친 CSS도 블록으로 되살릴 수 있습니다.
  - 꺼진 블록은 합친 CSS에 들어가지 않으므로 되살아나지 않습니다.
  - 주석이 없으면 전체를 블록 하나로 추가합니다.

## 주의

적용 후에는 Custom CSS 칸이 "합친 결과가 저장되는 곳"이 됩니다. 칸을 직접 고치면 다음 [적용] 때 덮어쓰이니, 수정은 블록에서 하세요.

## 업데이트

플러그인에 `//@update-url`이 들어 있어서, 이 저장소의 파일 버전(`//@version`)이 올라가면 PocketRisu 플러그인 설정에서 업데이트할 수 있습니다.
